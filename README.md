# Obiettivo 

Creare una serie di lezioni passo passo per un corso per la creazione di una radio con le seguenti caratteristiche:

- breadboard 
- ESP 32
- display
- funzioni : FM, DAB, USB Mp3, Internet Radio, Sveglia
- orario, preset ed altro
- Amplificatore
- Cassa di test
- Regolatori manopole e pulsante accensione

Ogni lezione deve essere caratterizzata:

- materiale
- istruzioni
- test di funzionamento

Ogni lezione deve portare alla costruzione della radio finale.

Prima di iniziare la creazione del progetto, 
- cerca in rete se esiste qualcosa di simili
- analizza ed individua i componenti, cercando quelli di uso comune 
- evidenzia particolari criticità
